# Role packs

One short file per worker role. The PM pastes the pack for the worker's role into the brief, above the footer, so a worker reads only the rules that apply to its job (decision 24, improvement A). Rules every worker needs are in [AGENTS.md](../../../AGENTS.md) and the [footer](../AGENT_BRIEF_FOOTER.md). Where each older rule went: [docs/agents/rule-map.md](../../../docs/agents/rule-map.md).

| Role | Pack | Use for |
| --- | --- | --- |
| implementer | [implementer.md](implementer.md) | feature, code and fix briefs |
| reviewer | [reviewer.md](reviewer.md) | review, re-review, pre-mortem |
| scout | [scout.md](scout.md) | read-only search, digest, hazard map, audit, cold read |
| researcher | [researcher.md](researcher.md) | external sources and research notes |
| runner | [runner.md](runner.md) | live runs, measurements, benchmarks |
