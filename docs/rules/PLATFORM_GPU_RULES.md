# Platform, Build and GPU-Scaling Rules (detail of AGENTS.md sections 4 and 8)

Binding detail of AGENTS.md sections 4, 6, 7 and 8, which keep a headline for each and link here.

- **Worktrees** reuse the canonical `.venv` read-only and own source, temp files and caches. Disable user-site packages and dependency bytecode; when `python.package` is set in `.agents/project.json`, assert its import origin in parent/child and copied-source tests. Only the PM coordinates approved dependency changes; resolve proven conflicts in an approved project-local environment, never globally.
- **Builds:** keep downloads/build caches, temp trees, isolation environments, wheelhouses, wheels and compiled outputs under the project root; first verify package-manager, build-tool and subprocess cache/temp/output settings and stop and report if a tool cannot comply.
- **Scaling self-hosted GPU services** (VLM, segmentation, embedding, editing) from 1 to many GPUs: use every selected compatible GPU within validated limits; shard a model only when one request needs it, with backend-supported sharding; never silently ignore a configured GPU; report effective topology and fail clearly when unsupported. A design and test requirement, not a claim that multi-GPU inference was measured.
- Training, when in scope, uses DDP or FSDP plus DeepSpeed or equivalent sharding when state does not fit (DDP is not sharding; validate compatibility). Large-model inference uses supported sharding or offload, or reports a clear limit.
- **Delete temp files as soon as done. Before handoff each agent removes its own `.tmp/` trees (pytest basetemps, mutant and copied-source trees, caches, OS-temp redirects, generated test credentials), keeping only small reports its handoff cites; permission-restricting tests restore them in teardown. After an integration is pushed and CI is green, the PM removes the integrated worktree and its `.tmp`, archiving cited reports under `.tmp/pm-archive/`. Never delete `models/`, `.venv/`, `.secrets/`, `runs/` evidence, ledgers or a tree a running task uses, and never recurse through a junction or link. Report space reclaimed and anything left.
- **CI:** GitHub Actions on the latest Ubuntu and Windows runners, with the repository public only for the run (R-025; procedure in [ci](../ci.md)). Report OS- or hardware-specific live tests separately; mark them `not_run` on unavailable targets, never inferred from another platform.
- **GPU smoke scripts:** documented simple scripts use real selected implementations on the user's server, write artifacts/environment metadata and fail/skip transparently. Distinguish unit, mock/contract, replay, CPU/GPU/cloud live, quality review and performance. Compilation or HTTP 200 does not prove a correct edit ([docs/test-plan.md](../test-plan.md)).
